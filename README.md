# Nexora social posts (review queue)

Roz ki Nexora posts yahan banti hain. Nexora WhatsApp agent har nayi post Rana sahab ko WhatsApp par bhejta hai;
jawab `ok <ref>` ya `change <ref> <tabdeeli>` yahan `decisions/` mein likha jata hai. Ok ke baad post Metricool se
Facebook, TikTok aur YouTube par lagti hai.

- `queue/<ref>.json`  post (status: review / scheduled)
- `posts/<ref>/v<N>/` tasveerein aur video
- `decisions/`        Rana sahab ke jawab (agent likhta hai)
- `kit/`              template, services aur tareeqa (kit/README.md)

Is repo mein koi password ya token kabhi na rakhein.
